# Todoアプリ

Djangoを使用して制作したTodo管理アプリです。

## 概要

Webアプリケーション開発の学習を目的として制作しました。

Todoの登録・管理を行えるシンプルなWebアプリとして、Djangoの基本的な仕組みや、データベースを利用したWebアプリケーションの開発について学習しました。

## 使用技術

* Python
* Django
* HTML
* CSS
* Bootstrap
* SQLite

## 主な機能

* Todoの一覧表示
* Todoの登録
* Todoの編集
* Todoの削除
* データベースへのTodo情報の保存

## 制作を通して学んだこと

Djangoを使用したWebアプリケーションの基本的な構成について学習しました。

また、画面側のHTML・CSSだけでなく、Python・Djangoを使用してデータを扱う処理を実装することで、Webアプリケーションがどのように動作するのかを学びました。

## 今後取り組みたいこと

今後は、ユーザー認証や機能の追加などに取り組み、より実用的なWebアプリケーションを制作できるよう、PythonやWeb開発に関する知識を深めていきたいと考えています。
